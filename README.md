# Tyhmäjatka

A modern web application built with Vite, HTML, CSS, and JavaScript.

## Features

- ⚡ Fast development with Vite
- 🎨 Modern CSS styling with gradients and animations
- 📱 Responsive design
- 🔧 Hot module replacement
- 🚀 Production-ready build

## Getting Started

### Prerequisites

- Node.js (version 16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd tyhmajatka
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:3000`

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build

## Development

The project uses Vite for fast development with hot module replacement. Any changes you make to the HTML, CSS, or JavaScript files will be automatically reflected in the browser.

## Building for Production

To create a production build:

```bash
npm run build
```

The built files will be in the `dist` directory.

## Technologies Used

- **Vite** - Build tool and development server
- **HTML5** - Semantic markup
- **CSS3** - Modern styling with flexbox, grid, and animations
- **Vanilla JavaScript** - No frameworks, just pure JS
